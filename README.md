## 📌 Project Overview

This project is an **interactive Sales Performance Dashboard created using Microsoft Excel**.  
The dashboard provides a clear overview of sales performance across different **cities and sales executives**.

It helps analyze total sales, target achievement, and the performance gap from the assigned target.

## 🎯 Objectives

- Analyze sales performance of individual sales executives.
- Compare sales performance across different cities.
- Track total sales achieved.
- Analyze target hit percentage.
- Identify the gap between actual sales and target sales.
- Create an interactive and easy-to-understand dashboard.

## 🛠️ Tools & Technologies Used

- **Microsoft Excel**
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Slicers / Filters
- Data Cleaning & Formatting
- Dashboard Design

## 📊 Dashboard Features

The dashboard includes:

- 🏙️ **City-wise Sales Analysis**
- 👤 **Sales Executive Performance**
- 💰 **Total Sales**
- 🎯 **Target Hit %**
- 📉 **Away From Target %**
- 📊 Sales comparison charts
- 🥧 Target achievement visualization
- 🔍 Interactive city filters

## 📈 Key Analysis

The dashboard helps answer questions such as:

- Which sales executive generated the highest sales?
- How much total sales were achieved?
- Which executives are closest to their targets?
- What percentage of the target has been achieved?
- Which cities have better sales performance?
- How far are executives from their assigned targets?
